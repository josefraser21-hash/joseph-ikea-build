# Durata Powercore Configurator

An interactive **Powercore Configurator** built as a single self-contained
HTML file — a UX portfolio mockup for [Durata Global](https://durata-global.com),
a modular data centre and critical power infrastructure company.

## Run it

Open `index.html` in any modern browser. No server, no build step, no
dependencies (other than the Inter web font).

## Highlights

- 32×32 dark "void" canvas with click-to-place 3D-style modular Powercore units
- Three module sizes — 1MW / 2.4MW / 5MW (size locks once you start placing)
- Drop-in animation with bounce, CSS dust particles, and a Web Audio thud
- Live count-up stats panel (capacity, power, mechanical, UPS, footprint)
- Lead-capture gate after the 4th unit, with a soft-gate nudge
- Durata-styled navy/cyan theme; responsive down to 1280px
